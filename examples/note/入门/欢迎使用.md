# 欢迎使用 MyKB

MyKB 将磁盘上的 Markdown 文件整理为可以搜索、编辑与收藏的知识库。

## 写下你的第一篇笔记

点击「新建文档」，填写标题与分类，再直接编辑正文。保存时会写回源文件，修改前会自动备份。

## 账号与收藏

管理员可以为不同用户设置分类可见性和文档操作权限。站内收藏、网络文章、学习进度与代码草稿分别保存在各自账号中。

## Markdown 示例

- **重点**可以加粗。
- 行内代码：`print("Hello, MyKB!")`。
- 数学公式：$a^2 + b^2 = c^2$。

```python
def greet(name):
    return f"Hello, {name}!"
```
